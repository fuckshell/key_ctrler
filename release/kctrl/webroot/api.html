KCtrl API

概述

KCtrl API 是一个基于标准 Linux 的输入设备监听软件，用于实时捕获和处理标准输入设备事件，并根据配置执行对应操作。支持自动化快捷键管理、触发脚本，可广泛用于手机/手表等按键自定义操作场景。

主要功能

  • 输入设备监听：支持单个或多个设备路径，捕获按键、点击、长按、双击事件。
  • 脚本执行：可为每个按键事件配置独立脚本，实现自定义逻辑。
  • CPU 亲和性：指定程序运行核心，提高性能并避免干扰其他任务。
  • 时间阈值：灵活设置点击、短按、长按及双击时间。
  • 日志管理：可开启或关闭日志，方便调试和监控操作。
  • 情景模式与系统控制：支持响铃、震动、静音、勿扰等系统模式控制。
  • 与常用 App 联动：可通过 shell 指令控制微信、支付宝、音乐、拍照、录屏等应用。

配置文件示例

# KCTRL 配置文件
# 格式: key=value
# 以#开头的行为注释

device=/dev/input/event0
cpu_affinity=0
click_threshold=200
short_press_threshold=1000
long_press_threshold=2000
double_click_interval=300
enable_log=0

# KEY735 按键脚本
script_735_click=key735_click.sh
script_735_double_click=key735_double.sh
script_735_short_press=key735_short.sh
script_735_long_press=key735_long.sh

已弃用 API

早期版本支持 name 参数来指定设备名称以便日志显示，但该 API 已被弃用，不建议使用。现代配置仅需设备路径和事件脚本即可完成所有操作。

# 过时示例
name=Power Button

使用建议

  • 尽量避免使用已弃用的 name 参数，现代版本无需指定设备名称。
  • 在配置 CPU 亲和性时，根据设备核心数量合理分配，防止性能浪费或干扰系统任务。
  • 脚本执行路径建议使用绝对路径或存放在固定目录，确保事件触发时可被正确调用。
  • 常用 App 指令可结合逻辑控制类命令，实现自动化场景，如音乐控制、通知模式切换等。
  • 建议开启日志调试初期配置，以便确认事件是否被正确捕获和执行。
